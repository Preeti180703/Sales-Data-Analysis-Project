# Sales Data Analysis & Power BI Dashboard

##  Project Overview

This project focuses on analyzing sales data using Excel, SQL, Python, and Power BI to identify sales trends, customer behavior, product performance, and business insights.

The project includes data cleaning, exploratory data analysis, SQL-based analysis, and an interactive Power BI dashboard to support data-driven decision-making.

##  Project Objectives

- Analyze overall sales and profit performance
- Identify top-performing products and categories
- Analyze sales trends over time
- Compare regional and customer segment performance
- Identify patterns and areas for business improvement
- Build an interactive dashboard for business reporting

##  Tools & Technologies

- **Excel** – Data cleaning, preprocessing and initial analysis
- **SQL** – Data querying and business analysis
- **Python** – Exploratory Data Analysis and visualization
- **Pandas & NumPy** – Data manipulation and analysis
- **Matplotlib & Seaborn** – Data visualization
- **Power BI** – Interactive dashboard and KPI reporting
- **DAX & Power Query** – Calculations and data transformation

##  Project Workflow

1. Collected and inspected the sales dataset
2. Cleaned and prepared the data using Excel and Power Query
3. Performed SQL queries to answer business questions
4. Conducted exploratory data analysis using Python
5. Created visualizations to identify trends and patterns
6. Built an interactive Power BI dashboard
7. Generated actionable business insights and recommendations

##  Key Analysis

- Sales and profit analysis
- Monthly and yearly sales trends
- Regional performance analysis
- Category and sub-category analysis
- Product performance analysis
- Customer segment analysis
- Shipping/payment mode analysis
- KPI analysis

##  Key Insights

The analysis helps identify:

- High-performing products and categories
- Top-performing and underperforming regions
- Sales and profit trends over time
- Customer segments contributing most to revenue
- Areas where business performance can be improved
